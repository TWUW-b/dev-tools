# 画像と動画の撮り方・説明の書き方

リリースノートで一番伝わるのはメディア。文章を読まなくても何が変わったか分かるように撮る。
そのかわり、**説明の無いメディアは載せない**。画像だけ並べても、どの変更の何を見ればよいかは読み手に分からない。

## 区分ごとに撮るもの

| 区分 | 既定 | 理由 |
|---|---|---|
| 直したこと | `after` の動画（直す前の挙動を見せたほうが伝わるときは `before` の動画も） | 「どう直ったか」は動きでしか示せない |
| 使いやすくしたこと | `before` と `after` の静止画 | 見比べると違いが一目で分かる。表示では横に並ぶ |
| 新しくできること | `howto` の動画 | 「どう使うか」を最初から最後まで見せる |
| 号全体 | `cover`（`overview` の静止画、任意） | 一覧カードに出る |

画面で見て分からない変更（メールの文面だけ、など）は、メディアを付けずに `media_waived` に理由を書く。

## 1 つのメディアに書く 4 つ

| フィールド | 中身 | 例 |
|---|---|---|
| `kind` | `before` / `after` / `howto` / `overview` | `after` |
| `caption` | 何が写っているかを 1 文。動画は「修正後: 」「使い方: 」で始める | 修正後: 担当者を変えるとすぐ保存できます |
| `description` | どこを見ればよいか。動画は秒数を添える | 0:03 で担当者を選び直すと保存ボタンが青くなり、0:06 で保存すると一覧に戻ります |
| `alt` | 画面を見られない人向けの代替テキスト。写っている内容を具体的に | 見出しの右に「全 24 件」と表示された案件一覧 |

`description` は「見どころ」であって、`after`（項目の文）の言い換えではない。画面のどの位置で何が起きるかを書く。

## ファイルの置き場と名前

```
docs/release-notes/<YYYY-MM-DD>-<短い名前>/
  release.json
  media/
    00-overview.png          … cover
    01-after.mp4             … 1 つ目の項目の変更後
    02-before.png
    02-after.png
    03-howto.mp4
```

- 名前は `<項目の番号 2 桁>-<kind>[-連番].<拡張子>`。番号は release.json の items の並び順。
- 使える形式: png / jpg / webp / gif / mp4 / webm / mov。SVG は使えない。
- 原稿フォルダごとホストアプリのリポジトリにコミットする。本番への投入し直しにそのまま使える。
  `preview.html` と `pushed.*.json` は作り直せる／環境ごとの記録なので、コミットしない（.gitignore に入れる）。

## 撮る前に

- **テストデータだけを写す。** 本番や実在の顧客・個人の情報が写ったものは使わない。社外にも出る前提で撮る。
- 画面の幅は利用者がよく使う幅にそろえる（PC 向けなら 1280px 前後）。
- 余計な通知やデバッグ表示を消してから撮る。

## 静止画

chrome-devtools-mcp の `take_screenshot` で撮る。

- `before` と `after` は同じ画面・同じ幅・同じデータで撮る。違いが変更点だけになるようにする。
- 見せたい場所が小さいときは、その部分を含む範囲に絞る（要素を指定して撮る）。

## 動画

chrome-devtools-mcp の `screencast_start` / `screencast_stop` で撮る。

- 1 本 10〜18 秒。1 本で見せる状態の変化は 1 つだけ（「X すると Y になる」）。
- 操作の前に 1 秒ほど止めて、最初の状態を見せてから動かす。
- 撮ったら圧縮する。**解像度は落とさない**（文字が読めなくなる）。

```bash
ffmpeg -i raw.mp4 -ss 00:00:01 -to 00:00:16 -c:v libx264 -crf 28 -preset slow -pix_fmt yuv420p -movflags +faststart -an media/01-after.mp4
```

- 目安は 1 本 250KB 前後。2MB を超えると検査で warning が出る。上限は 50MB。
- 音声は入れない（`-an`）。

## 表示のされ方

- 項目の下に、札（変更前／変更後／使い方／全体像）→ 本体 → caption → description の順で出る。
- `before` と `after` がそろうと横に並ぶ（狭い画面では縦）。
- 動画は冒頭のフレームが出た状態で止まっていて、押すと再生する。
- 画像は押すと拡大する。
